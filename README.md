# Colheita Vitural — HTML5

Reconstrução experimental de um jogo rural 3D em HTML5 e Babylon.js. Desenvolvimento em andamento, sem Godot. O código da Etapa 1H foi importado em um histórico público independente; versões anteriores e assinatura Android permanecem em armazenamento privado.

## Testes

Em `html5-babylon/`, execute `npm install`, `npm run build` e `npm test` após iniciar um servidor HTTP da pasta `dist` na porta 4173. O GitHub Actions automatiza compilação, validação da planta, regressão do motor e capturas reais. O workflow não publica APKs.

## Estado

Etapa 1H: residência, vegetação e perspectiva. Não é uma versão de produção. Consulte `CONTEXTO_E_MEMORIA/ESTADO.md`. Direitos autorais reservados; nenhuma licença de redistribuição do código foi concedida neste repositório.
